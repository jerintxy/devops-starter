# DevOps Starter

## About
This project is a simple Python calculator created as part of a DevOps learning exercise.

## Features
The calculator supports:
- Addition
- Subtraction
- Multiplication
- Division
  
## How to Run
Make sure Python is installed, then run:
python calculator.py
